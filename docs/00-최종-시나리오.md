# MCP & A2A 오케스트레이션 시나리오

이 프로젝트는 **MCP (Model Context Protocol)**와 **A2A (Agent-to-Agent)** 오케스트레이션을 학습하기 위한 실습용 프로젝트입니다.

---

## 🎯 학습 목표

이 프로젝트를 통해 다음을 학습할 수 있습니다:

- ✅ **MCP 서버 구현**: AI 모델이 도구(Tool)로 사용할 수 있는 API 서버
- ✅ **자연어 입력 처리**: 사용어 쿼리 이해 및 파싱
- ✅ **A2A 오케스트레이션**: 여러 에이전트 간의 협업 패턴
- ✅ **Tool 호출**: AI 모델이 외부 API를 호출하는 방식
- ✅ **응답 포맷팅**: API 결과를 자연어로 변환

---

## 🤖 MCP & A2A란?

### MCP (Model Context Protocol)
- AI 모델이 **외부 도구(Tools)**와 **데이터 소스**에 접근하는 표준 프로토콜
- AI 모델이 검색, 계산, API 호출 등을 할 수 있게 해줌

### A2A (Agent-to-Agent)
- 여러 **전문화된 에이전트**가 협력하여 복잡한 작업을 해결하는 패턴
- 각 에이전트가 특정 역할을 맡고 서로 통신하며 문제 해결

---

## 🎬 시나리오: 항공편 검색 A2A

### 시나리오 개요

사용자가 자연어로 항공편을 검색하면, 여러 전문 에이전트가 협력하여 최적의 항공편을 찾아주는 시스템

## 📝 입출력 예시

### 예시 1: 기본 검색 (항공사별 그룹핑)

**입력 (자연어)**
```
"내일 광주에서 제주로 가는 항공편 알려줘"
```

**처리 과정 (A2A 오케스트레이션)**
```
[Coordinator Agent]
    ↓ 사용자 의도 파악

[Date Parser Agent]
    ↓ "내일" → 2026-03-11 변환

[Airport Code Agent]
    ↓ "광주" → NAARKJJ
    ↓ "제주" → NAARKPC

[Flight Search Agent]
    ↓ 공공데이터 API 호출
    ↓ 항공편 목록 조회

[Grouping Agent]
    ↓ 항공사별로 그룹핑

[Response Formatter Agent]
    ↓ 결과를 자연어로 변환
```

**출력 (자연어)**
```
네, 내일 광주에서 제주로 가는 항공편을 찾았어요!

📊 항공사별 정렬된 결과입니다.

──────────────────────
✈️ 아시아나항공 (2편)
──────────────────────

1. OZ8141편
   출발: 09:55 → 도착: 11:25
   가격: 57,900원

2. OZ8143편
   출발: 14:30 → 도착: 16:00
   가격: 62,000원

──────────────────────
✈️ 제주항공 (3편)
──────────────────────

1. 7C1402편
   출발: 10:30 → 도착: 12:00
   가격: 45,000원

2. 7C1404편
   출발: 13:00 → 도착: 14:30
   가격: 48,000원

3. 7C1406편
   출발: 16:00 → 도착: 17:30
   가격: 52,000원

──────────────────────
✈️ 에어부산 (1편)
──────────────────────

1. BX1234편
   출발: 15:20 → 도착: 16:50
   가격: 49,000원

──────────────────────
총 6편의 항공편이 있으며,
가장 저렴한 항공편은 제주항공 7C1402편으로 45,000원입니다.
```

## 🏗️ A2A 에이전트 구조

### 에이전트 역할

| 에이전트 | 역할 | 관련 기능 |
|---------|------|----------|
| **Coordinator Agent** | 전체 조율 | 사용자 의도 파악, 작업 분배 |
| **Date Parser Agent** | 날짜 해석 | "내일", "모레" → 구체 날짜 |
| **Airport Code Agent** | 공항 코드 매핑 | "광주" → NAARKJJ |
| **Airport List Agent** | 공항 목록 조회 | 공항 정보 반환 |
| **Airline List Agent** | 항공사 목록 조회 | 항공사 정보 반환 |
| **Flight Search Agent** | 항공편 검색 | 공공데이터 API 호출 |
| **Grouping Agent** | 항공사별 그룹핑 | 항공사별로 정리 |
| **Time Filter Agent** | 시간 필터링 | 출발/도착 시간 조건 |
| **Price Filter Agent** | 가격 필터링 | 예산에 맞는 가격 |
| **Price Comparison Agent** | 가격 비교 | 항공사별 가격 분석 |
| **Recommendation Agent** | 추천 로직 | 최적 항공편 선정 |
| **Response Formatter Agent** | 응답 포맷팅 | 결과를 자연어로 변환 |

### 에이전트 간 통신 예시

```
User: "오후 2시 이후 광주-제주 항공편"
    ↓
Coordinator → AirportCode: "광주, 제주 → 코드 변환"
AirportCode → Coordinator: "NAARKJJ, NAARKPC"
    ↓
Coordinator → FlightSearch: "항공편 검색"
FlightSearch → Coordinator: "6개 항공편 찾음"
    ↓
Coordinator → TimeFilter: "14:00 이후 필터링"
TimeFilter → Coordinator: "3개 항공편 남음"
    ↓
Coordinator → Grouping: "항공사별 그룹핑"
Grouping → Coordinator: "아시아나1편, 제주2편"
    ↓
Coordinator → ResponseFormatter: "자연어로 변환"
ResponseFormatter → User: "오후 2시 이후 항공편입니다..."
```
