# 항공 스케줄 API 프로젝트 가이드

## 📋 프로젝트 소개

이 프로젝트는 **국토교통부 국내항공운항정보 API**를 활용하여 항공 스케줄 조회 서비스를 구현하는 실습용 프로젝트입니다.

### 🎯 학습 목표

이 프로젝트를 통해 다음을 학습할 수 있습니다:

- ✅ **외부 REST API 연동**: RestTemplate을 사용한 공공데이터 호출
- ✅ **Spring Boot MVC 구조**: Controller → Service → API Client 계층 이해
- ✅ **JSON 데이터 파싱**: API 응답을 DTO로 매핑
- ✅ **사용자 입력 처리**: 검색 폼에서의 데이터 수집 및 검증
- ✅ **데이터 변환**: 외부 API 포맷에서 서비스 포맷으로 변환
- ✅ **예외 처리**: API 호출 실패, 검증 에러 처리

> **참고**: 이 프로젝트는 스프링 기초 + 외부 API 연동 학습용입니다. A2A 오케스트레이션(여러 마이크로서스 협업)은 다음 단계인 "여행 일정 계획 서비스"에서 다루면 더 좋습니다.

### 주요 기능

1. **항공운항정보 조회**: 출/도착지 기준 국내선 항공편 정보 제공
2. **공항 목록 조회**: 전체 공항 코드 및 이름 제공
3. **항공사 목록 조회**: 전체 항공사 코드 및 이름 제공

## 🎬 사용자 시나리오

### 항공편 검색 흐름

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  사용자     │ ───> │  웹페이지   │ ───> │  백엔드 API │ ───> │ 공공데이터  │
│             │      │  (검색폼)   │      │  (Spring)   │      │   포털      │
└─────────────┘      └─────────────┘      └─────────────┘      └─────────────┘
                          │                      │                      │
                     출발지 선택            검증 & 변환          API 호출
                     도착지选择            비즈니스 로직        데이터 파싱
                     날짜 선택              예외 처리           응답 반환
```

### 학습 포인트

1. **사용자 입력 처리**: HTML Form → Controller
2. **데이터 검증**: @Valid, @Pattern 등
3. **서비스 로직**: 입력 → API 요청 파라미터 변환
4. **외부 API 연동**: RestTemplate으로 공공데이터 호출
5. **데이터 매핑**: JSON 응답 → DTO → 사용자 응답
6. **예외 처리**: API 에러, 검증 에러 처리
