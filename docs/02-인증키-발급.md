# 공공데이터 포털 인증키 발급 가이드

## 📝 Step 1: 공공데이터 포털 가입

1. **공공데이터포털 접속**
   - URL: https://www.data.go.kr/

2. **회원가입**
   - 상단 메뉴의 `[회원가입]` 클릭
   - 필요 정보 입력 후 가입 완료

---

## 🔑 Step 2: API 활용신청

1. **로그인 후 페이지 접속**
   - URL: https://www.data.go.kr/data/15098526/openapi.do#/

2. **[활용신청] 버튼 클릭**

   ![활용신청 버튼 위치](./images/api-apply-button.png)

3. **신청서 작성**

   | 항목 | 설명 | 예시 |
   |------|------|------|
   | 활용목적 | API 사용 목적 | 학습 및 연구용 |
   | 제공기관 | 자동 입력 | 국토교통부 |
   | 승인일자 | 자동 승인 | 즉시 승인 |
   | 일일트래픽 | 개발계정 | 10,000회/일 |

4. **[신청완료] 클릭**

---

## 🎫 Step 3: 인증키 확인

1. **마이페이지 접속**
   - 로그인 후 `[마이페이지]` > `[데이터활용]` > `[오픈API]` 클릭

2. **발급받은 키 확인**
   - **개발계정(Decoding)** 키 복사
   - 형식: `서비스키=알파벳+숫자조합` (약 100자리)

3. **키 안전하게 보관**
   - 프로젝트의 `application.yml`에 설정 예정

---

## ⚠️ 주의사항

### 1. 인증키 종류

| 종류 | 설명 |
|------|------|
| **Decoding** (추천) | 인코딩되지 않은 일반 텍스트 |
| Encoding | URL 인코딩된 키 (특수문자 포함) |

### 2. 트래픽 제한

- **개발계정**: 10,000회/일
- **운영계정**: 활용사례 등록 시 증가 가능

### 3. 도메인 등록

- 운영 시 사용할 도메인 등록 필요
- 로컬 개발 시: `localhost:8080` 등록 권장
