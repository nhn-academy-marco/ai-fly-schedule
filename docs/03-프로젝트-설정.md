# 프로젝트 설정 가이드

## 📦 Spring Boot 프로젝트 생성

### 방법 1: Spring Initializr (웹)

1. **https://start.spring.io/ 접속**

2. **프로젝트 설정**

   | 항목 | 값 |
   |------|-----|
   | Project | Maven Project |
   | Language | Java |
   | Spring Boot | 4.0.x (최신 버전) |
   | Group | com.nhnacademy |
   | Artifact | flyschedule |
   | Name | flyschedule |
   | Package name | com.nhnacademy.flyschedule |
   | Packaging | Jar |
   | Java | 21 |

3. **Dependencies 추가**

   ```
   - Spring Web MVC
   - Lombok
   - Spring Boot DevTools (선택)
   - Validation (선택)
   ```

4. **[GENERATE] 클릭** 후 압축 해제

### 방법 2: IntelliJ IDEA (추천)

1. **New Project** > **Spring Initializr**
2. 위와 동일한 설정 입력
3. **Create** 클릭

## 📝 pom.xml 설정

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>4.0.3</version>
        <relativePath/>
    </parent>

    <groupId>com.nhnacademy</groupId>
    <artifactId>flyschedule</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <name>flyschedule</name>
    <description>항공 스케줄 API 프로젝트</description>

    <properties>
        <java.version>21</java.version>
    </properties>

    <dependencies>
        <!-- Spring Web MVC -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Lombok -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <optional>true</optional>
        </dependency>

        <!-- Validation (선택) -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

        <!-- 개발용 도구 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-devtools</artifactId>
            <scope>runtime</scope>
            <optional>true</optional>
        </dependency>

        <!-- 테스트 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
                <configuration>
                    <excludes>
                        <exclude>
                            <groupId>org.projectlombok</groupId>
                            <artifactId>lombok</artifactId>
                        </exclude>
                    </excludes>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>
```

## ⚙️ application.yml 설정

`src/main/resources/application.yml` 파일 생성:

```yaml
server:
  port: 8080

spring:
  application:
    name: flyschedule

# 공공데이터 포털 API 설정
data-go-kr:
  api:
    url: https://apis.data.go.kr/1613000/DmstcFlightNvgInfo
    service-key: "발급받은_인증키를_여기에_입력"

# 로깅 설정
logging:
  level:
    com.nhnacademy.flyschedule: DEBUG
```

### 인증키 설정 방법

**방법 1: 직접 입력 (개발용)**
```yaml
service-key: "abcd1234...실제키..."
```

**방법 2: 환경변수 사용 (운영용 추천)**
```yaml
service-key: ${DATA_GO_KR_SERVICE_KEY}
```

 IntelliJ에서 환경변수 설정:
- `Run` > `Edit Configurations` > `Environment variables`
- `DATA_GO_KR_SERVICE_KEY=실제키` 입력

## 📂 패키지 구조 생성

```
src/main/java/com/nhnacademy/flyschedule/
├── FlyScheduleApplication.java    # 메인 클래스 (자동 생성)
├── controller/
│   └── FlightController.java      # 항공편 조회 컨트롤러
├── service/
│   ├── FlightService.java         # 항공편 비즈니스 로직
│   └── ApiClientService.java      # 외부 API 호출 서비스
├── dto/
│   ├── request/                   # 요청 DTO
│   │   └── FlightSearchRequest.java
│   └── response/                  # 응답 DTO
│       ├── FlightInfoResponse.java
│       └── AirportInfoResponse.java
└── config/
    └── RestTemplateConfig.java    # RestTemplate 설정
```

빈 패키지 생성 (macOS/Linux):
```bash
mkdir -p src/main/java/com/nhnacademy/flyschedule/controller
mkdir -p src/main/java/com/nhnacademy/flyschedule/service
mkdir -p src/main/java/com/nhnacademy/flyschedule/dto/request
mkdir -p src/main/java/com/nhnacademy/flyschedule/dto/response
mkdir -p src/main/java/com/nhnacademy/flyschedule/config
```

빈 패키지 생성 (Windows):
```bash
mkdir src\main\java\com\nhnacademy\flyschedule\controller
```

## ✅ 설정 확인

### 1. 의존성 다운로드

```bash
mvn clean install
```

IntelliJ: 우측 상단 Maven 탭 > Reload 클릭

### 2. 프로젝트 실행

```bash
mvn spring-boot:run
```

또는 IntelliJ에서 `FlyScheduleApplication` 메인 메서드 실행

### 3. 정상 실행 확인

콘솔에서 다음 로그 확인:
```
Started FlyScheduleApplication in X.XXX seconds
Tomcat started on port(s): 8080 (http)
```

### 4. 브라우저 접속

```
http://localhost:8080
```

## 🔧 공통 설정 클래스

### RestTemplateConfig.java

```java
package com.nhnacademy.flyschedule.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.client.RestTemplate;

@Configuration
public class RestTemplateConfig {

    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

## 📌 Maven 주요 명령어

| 명령어 | 설명 |
|--------|------|
| `mvn clean install` | 프로젝트 빌드 및 로컬 저장소에 설치 |
| `mvn clean compile` | 소스 코드 컴파일 |
| `mvn clean package` | JAR 파일 생성 |
| `mvn spring-boot:run` | 애플리케이션 실행 |
| `mvn test` | 테스트 실행 |
| `mvn clean` | 빌드 파일 삭제 |
