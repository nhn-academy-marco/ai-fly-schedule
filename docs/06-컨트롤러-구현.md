```java
package com.example.flyschedule.dto.request;

import lombok.Data;

@Data
public class FlightSearchRequest {

    // 필수 파라미터
    private String depAirportId;   // 출발공항ID (예: NAARKJJ - 광주)
    private String arrAirportId;   // 도착공항ID (예: NAARKPC - 제주)
    private String date;           // 조회일자 (YYYY-MM-DD)

    // 선택 파라미터
    private String airlineId;      // 항공사ID (예: AAR - 아시아나)
    private Integer minPrice;      // 최소 가격
    private Integer maxPrice;      // 최대 가격
}
```

## 🎮 컨트롤러 구현

### FlightController.java

```java
package com.example.flyschedule.controller;

import com.example.flyschedule.dto.request.FlightSearchRequest;
import com.example.flyschedule.dto.response.ApiResponse;
import com.example.flyschedule.dto.response.FlightInfoResponse;
import com.example.flyschedule.service.FlightService;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@Slf4j
@RestController
@RequestMapping("/api/flights")
@RequiredArgsConstructor
public class FlightController {

    private final FlightService flightService;

    /**
     * 항공편 검색
     *
     * @param request 검색 조건
     * @return 항공편 목록
     */
    @PostMapping("/search")
    public ApiResponse<List<FlightInfoResponse>> searchFlights(
            @RequestBody @Valid FlightSearchRequest request) {

        log.info("항공편 검색 요청: {}", request);

        // 항공편 조회
        List<FlightInfoResponse> flights = flightService.searchFlights(
                request.getDepAirportId(),
                request.getArrAirportId(),
                request.getDate()
        );

        // 필터링
        flights = flightService.filterFlights(
                flights,
                request.getAirlineId(),
                request.getMinPrice(),
                request.getMaxPrice()
        );

        return ApiResponse.success(flights);
    }

    /**
     * 항공편 검색 (GET 방식)
     *
     * @param depAirportId 출발공항ID
     * @param arrAirportId 도착공항ID
     * @param date         조회일자
     * @return 항공편 목록
     */
    @GetMapping("/search")
    public ApiResponse<List<FlightInfoResponse>> searchFlightsByGet(
            @RequestParam String depAirportId,
            @RequestParam String arrAirportId,
            @RequestParam String date) {

        log.info("항공편 검색 요청 (GET): {} -> {} ({})", depAirportId, arrAirportId, date);

        List<FlightInfoResponse> flights = flightService.searchFlights(
                depAirportId,
                arrAirportId,
                date
        );

        return ApiResponse.success(flights);
    }
}
```

## 🔧 Validation 추가

### 1. 의존성 추가

**build.gradle:**
```gradle
implementation 'org.springframework.boot:spring-boot-starter-validation'
```

### 2. DTO에 Validation 추가

```java
package com.example.flyschedule.dto.request;

import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Pattern;
import lombok.Data;

@Data
public class FlightSearchRequest {

    @NotBlank(message = "출발공항ID는 필수입니다.")
    private String depAirportId;

    @NotBlank(message = "도착공항ID는 필수입니다.")
    private String arrAirportId;

    @NotBlank(message = "조회일자는 필수입니다.")
    @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$", message = "날짜 형식이 올바르지 않습니다. (YYYY-MM-DD)")
    private String date;

    private String airlineId;
    private Integer minPrice;
    private Integer maxPrice;
}
```

## 📊 Swagger UI 설정 (선택)

### 1. 의존성 추가

```gradle
implementation 'org.springdoc:springdoc-openapi-starter-webmvc-ui:2.3.0'
```

### 2. 설정

```java
package com.example.flyschedule.config;

import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.info.Info;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class OpenApiConfig {

    @Bean
    public OpenAPI openAPI() {
        return new OpenAPI()
                .info(new Info()
                        .title("항공 스케줄 API")
                        .description("국내항공운항정보 조회 서비스")
                        .version("1.0"));
    }
}
```

### 3. 접속

```
http://localhost:8080/swagger-ui/index.html
```
