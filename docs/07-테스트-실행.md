### 테스트 4: Validation 에러

  -H "Content-Type: application/json" \

  }'

**예상 응답:**
```json

  "message": "날짜 형식이 올바르지 않습니다. (YYYY-MM-DD)",
  "data": null
}
```

## 🐛 문제 해결

### 문제 1: 인증키 에러

```
resultCode: "30"
resultMessage: "SERVICE KEY IS NOT REGISTERED ERROR"
```

**해결 방법:**
1. 공공데이터 포털에서 활용신청 확인
2. **Decoding** 키를 사용하는지 확인
3. `application.yml`의 키 값 확인

---

### 문제 2: 파라미터 에러

```
resultCode: "99"
resultMessage: "INVALID_REQUEST_PARAMETER_ERROR"
```

**해결 방법:**
1. 필수 파라미터 모두 전달 확인
   - `depAirportId`
   - `arrAirportId`
   - `depPlandTime` (YYYYMMDD 형식)

---

### 문제 3: 포트 충돌

```
Port 8080 was already in use
```

**해결 방법:**
```yaml
# application.yml
server:
  port: 8081  # 다른 포트로 변경
```

## 📊 통합 테스트 코드

### FlightControllerIntegrationTest.java

```java
package com.nhnacademy.flyschedule;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.AutoConfigureMockMvc;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.*;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

@SpringBootTest
@AutoConfigureMockMvc
class FlightControllerIntegrationTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @Test
    void 항공편_검색_통합_테스트() throws Exception {
        // given
        String requestBody = """
            {
              "depAirportId": "NAARKJJ",
              "arrAirportId": "NAARKPC",
              "date": "2025-03-09"
            }
            """;

        // when & then
        mockMvc.perform(post("/api/flights/search")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(requestBody))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.success").value(true))
                .andExpect(jsonPath("$.data").isArray());
    }
}
```
