# 자연어 항공편 검색 구현

이 문서는 LLM을 활용한 자연어 항공편 검색 기능의 구현 내용을 단계별로 설명합니다.

---

## 📋 개요

### 기능 설명

사용자가 자연어로 항공편 검색 요청을 하면, 두 가지 방식으로 검색을 수행합니다:
1. **Coordinator 방식**: 오케스트레이션 서비스가 여러 A2A 에이전트들을 조율
2. **A2A 방식**: LLM이 직접 MCP Tools를 선택하고 호출

### 사용 예시

```
입력: "2026년3월25일 광주에서 제주로 가는 10시 이후 항공편 조회 해줘"

추출된 파라미터:
- departure: "광주"
- arrival: "제주"
- date: "2026-03-25"
- afterTime: "10:00"

결과: 10시 이후 출발하는 광주-제주 항공편 목록
```

---

## 🏗️ 아키텍처

### 두 가지 구현 방식

#### 방식 1: Coordinator 방식 (권장)

```
사용자 입력 (자연어)
    ↓
NaturalLanguageSearchController
    ↓
NaturalLanguageOrchestrationService (Coordinator)
    ↓
┌─────────────────────────────────────┐
│ 1. LLM 파라미터 추출                   │
│ 2. 파라미터 검증                       │
│ 3. 날짜 처리 (DateParserAgent)          │
│ 4. 공항 코드 변환 (AirportCodeAgent)     │
│ 5. 항공편 검색 (FlightSearchAgent)       │
│ 6. 시간 필터링 (TimeFilterAgent)         │
│ 7. 가격 필터링 (PriceFilterAgent)        │
│ 8. 항공사별 그룹핑 (GroupingAgent)       │
└─────────────────────────────────────┘
    ↓
검색 결과 반환 (JSON)
```

**장점**:
- 각 단계별 로깅으로 디버깅 용이
- 에이전트들의 역할이 명확히 분리
- 유지보수가 쉬움
- 테스트가 용이

#### 방식 2: A2A 방식 (실험적)

```
사용자 입력 (자연어)
    ↓
NaturalLanguageSearchController
    ↓
A2ANaturalLanguageService
    ↓
ChatClient + Spring AI Function Calling
    ↓
LLM이 직접 MCP Tools 선택 및 호출
    ↓
Tool 실행 결과 → LLM
    ↓
LLM이 최종 응답 생성
```

**장점**:
- LLM의 추론 능력을 최대 활용
- 동적으로 Tool 선택 가능
- 새로운 Tool 추가 시 코드 수정 불필요
- 진정한 A2A 패턴

**단점**:
- LLM 호출로 인해 지연 시간 증가
- 디버깅이 어려움
- Ollama 연결 의존적

## 🔧 구현 상세

### 1. LlmAnalysisService

LLM을 사용하여 자연어 메시지에서 검색 파라미터를 추출합니다.

**파일**: `src/main/java/com/nhnacademy/flyschedule/service/LlmAnalysisService.java`

```java
@Service
public class LlmAnalysisService {

    private final ObjectMapper objectMapper = new ObjectMapper();
    private final RestTemplate restTemplate = new RestTemplate();

    @Value("${spring.ai.ollama.base-url}")
    private String baseUrl;  // http://ollama.java21.net

    @Value("${spring.ai.ollama.chat.options.model}")
    private String model;  // qwen2.5:latest

    /**
     * 자연어 메시지에서 항공편 검색 파라미터 추출
     */
    public Map<String, Object> extractFlightSearchParams(String message) {
        String prompt = buildAnalysisPrompt(message);

        // Ollama API 직접 호출
        String url = baseUrl + "/api/generate";

        Map<String, Object> request = new HashMap<>();
        request.put("model", model);
        request.put("prompt", prompt);
        request.put("stream", false);
        request.put("format", "json");

        Map<String, Object> response = restTemplate.postForObject(url, request, Map.class);

        String jsonResponse = (String) response.get("response");
        return parseResponse(jsonResponse);
    }
}
```

```java

        ## 추출할 파라미터
        - departure: 출발 공항 **이름** (예: 광주, 김포, 제주)
        - arrival: 도착 공항 **이름** (예: 광주, 김포, 제주)
        - date: 날짜 (YYYY-MM-DD 형식, 예: 2026-03-25)
        - afterTime: 기준 시간 (HH:MM 형식, 예: 10:00)

          "arrival": "제주",
          "date": "2026-03-25",
          "afterTime": "10:00",
          "beforeTime": null,
          "minPrice": null,
          "maxPrice": null
        }
        ```

        ## 사용자 메시지

        """, message);

### 2. NaturalLanguageSearchController

자연어 검색 API 엔드포인트를 제공합니다.

**파일**: `src/main/java/com/nhnacademy/flyschedule/controller/NaturalLanguageSearchController.java`

```java
@RestController
@RequestMapping("/api/nl-search")
@RequiredArgsConstructor
public class NaturalLanguageSearchController {

    private final LlmAnalysisService llmAnalysisService;
    private final AirportCodeAgent airportCodeAgent;
    private final FlightSearchAgent flightSearchAgent;
    private final TimeFilterAgent timeFilterAgent;
    private final PriceFilterAgent priceFilterAgent;
    private final GroupingAgent groupingAgent;

    /**
     * 자연어 항공편 검색
     */
    @PostMapping("/search")
    public Map<String, Object> searchByNaturalLanguage(@RequestBody Map<String, String> request) {
        String message = request.get("message");

        // 1. LLM로 파라미터 추출
        Map<String, Object> params = llmAnalysisService.extractFlightSearchParams(message);

        // 2. 필수 파라미터 검증
        if (!params.containsKey("departure") || !params.containsKey("arrival")) {
            return error("출발 공항과 도착 공항을 명확히 입력해주세요.");
        }

        // 3. 날짜 처리 (없으면 오늘)
        String dateStr = (String) params.getOrDefault("date", LocalDate.now().toString());

        // 4. 출발/도착 공항 코드 변환
        String departure = (String) params.get("departure");
        String arrival = (String) params.get("arrival");
        String depAirportId = airportCodeAgent.getAirportCode(departure);
        String arrAirportId = airportCodeAgent.getAirportCode(arrival);

        // 5. 항공편 검색
        Map<String, List<FlightInfoResponse>> flightsMap =
            flightSearchAgent.searchAndGroupByAirline(depAirportId, arrAirportId, dateStr);

        // 6. List로 변환
        List<FlightInfoResponse> flights = flightsMap.values().stream()
                .flatMap(List::stream)
                .collect(Collectors.toList());

        // 7. 시간 필터링
        if (params.containsKey("afterTime")) {
            String afterTime = (String) params.get("afterTime");
            LocalTime time = LocalTime.parse(afterTime);
            flights = timeFilterAgent.filterAfterTime(flights, time);
        }

        // 8. 가격 필터링
        if (params.containsKey("minPrice") || params.containsKey("maxPrice")) {
            Integer minPrice = params.containsKey("minPrice") ?
                    Integer.parseInt((String) params.get("minPrice")) : null;
            Integer maxPrice = params.containsKey("maxPrice") ?
                    Integer.parseInt((String) params.get("maxPrice")) : null;
            flights = priceFilterAgent.filterByPriceRange(flights, minPrice, maxPrice);
        }

        // 9. 항공사별 그룹핑
        Map<String, List<FlightInfoResponse>> groupedFlights = groupingAgent.groupByAirline(flights);

        // 10. 응답 반환
        return success(params, groupedFlights);
    }
}
```

### 3. AirportCodeAgent 개선

공항 이름뿐만 아니라 공항 코드도 처리할 수 있도록 개선했습니다.

**파일**: `src/main/java/com/nhnacademy/flyschedule/service/AirportCodeAgent.java`

```java
public String getAirportCode(String airportName) {
    String normalized = airportName.trim();

    // 이미 공항 코드 형식인 경우 (NAARKSS, NAARKJJ 등)
    if (normalized.matches("NAARK[A-Z]{2}")) {
        log.info("공항 코드 입력됨: {}", normalized);
        return normalized;
    }

    // 공항 이름으로 검색
    String code = AIRPORT_CODE_MAP.get(normalized);

    if (code == null) {
        throw new IllegalArgumentException("알 수 없는 공항입니다: " + airportName);
    }

    return code;
}
```

## 🐛 문제 해결

### 1. Ollama 연결 시간 초과

**증상**: `I/O error on POST request for "http://ollama.java21.net/api/generate": Operation timed out`

**해결**:
- Ollama 서버가 실행 중인지 확인
- 방화벽 설정 확인
- URL이 올바른지 확인

### 2. 공항 코드 인식 실패

**증상**: `알 수 없는 공항입니다: NAARKJJ`

**해결**:
- LLM 프롬프트에 "공항 코드 대신 한글 공항 이름만 사용" 명시
- AirportCodeAgent에서 공항 코드 형식도 처리하도록 개선

### 3. Spring AI 호환성 문제

**증상**: `No qualifying bean of type 'org.springframework.ai.chat.model.ChatModel'`

**해결**:
- Spring Boot 4.0.3과 Spring AI 1.1.2 호환성 문제
- Ollama auto-configuration 제외
- 직접 Ollama API 호출 방식으로 변경
