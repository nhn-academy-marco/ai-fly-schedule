## 🔧 테스트 도구

### JUnit 5 (Jupiter)
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```

**주요 기능:**
- `@Test`: 테스트 메서드 정의
- `@DisplayName`: 테스트 이름 설정
- `@ParameterizedTest`: 매개변수화된 테스트
- `@BeforeEach`: 각 테스트 전 실행
- `@CsvSource`: CSV 데이터 소스

### Mockito
```xml
<!-- spring-boot-starter-test에 포함됨 -->
```

**주요 기능:**
- `@Mock`: Mock 객체 생성
- `@InjectMocks`: Mock 객체 주입
- `@ExtendWith(MockitoExtension.class)`: Mockito 확장
- `when().thenReturn()`: Mock 동작 설정

### AssertJ
```xml
<!-- spring-boot-starter-test에 포함됨 -->
```

**주요 기능:**
- `assertThat()`: Assertion 시작
- `isEqualTo()`: 동등성 검증
- `hasSize()`: 컬렉션 크기 검증
- `containsKey()`: Map 키 포함 검증
- `isGreaterThan()`: 비교 검증

## 📝 테스트 작성 패턴

### 1. 단위 테스트 패턴

```java
@DisplayName("ServiceName 단위 테스트")
class ServiceNameTest {

    private ServiceName service;

    @BeforeEach
    void setUp() {
        service = new ServiceName();
    }

    @Test
    @DisplayName("테스트 설명")
    void testName_expectedBehavior() {
        // Given
        String input = "test";

        // When
        String result = service.method(input);

        // Then
        assertThat(result).isEqualTo("expected");
    }
}
```

### 2. Mock을 사용한 테스트 패턴

```java
@ExtendWith(MockitoExtension.class)
@DisplayName("ServiceName 통합 테스트")
class ServiceNameTest {

    @Mock
    private DependencyService dependencyService;

    @InjectMocks
    private ServiceName service;

    @Test
    @DisplayName("Mock을 사용한 테스트")
    void testName_withMock_returnsExpected() {
        // Given
        when(dependencyService.getData())
                .thenReturn(mockData);

        // When
        var result = service.process();

        // Then
        assertThat(result).isNotNull();
    }
}
```

### 3. Parameterized Test 패턴

```java
@ParameterizedTest
@CsvSource({
    "'오늘', 0",
    "'내일', 1",
    "'모레', 2"
})
@DisplayName("상대적 날짜 표현을 정확히 파싱해야 한다")
void parseDate_relativeDateExpressions(String input, int daysToAdd) {
    // When
    String result = dateParserAgent.parseDate(input);

    // Then
    assertThat(result).hasSize(8);
}
```

## 🎯 테스트 Best Practices

### 1. 테스트 명명 규칙
- **클래스명**: `{ServiceName}Test`
- **메서드명**: `{methodName}_{expectedBehavior}`

### 2. DisplayName 사용
```java
@DisplayName("서비스명 단위 테스트")
class ServiceNameTest {

    @Test
    @DisplayName("명확한 테스트 설명")
    void testMethod_clearDescription() {
        // 테스트 코드
    }
}
```

### 3. Given-When-Then 패턴
```java
@Test
void testMethod() {
    // Given: 테스트 데이터 준비
    String input = "test";

    // When: 테스트 대상 메서드 실행
    String result = service.method(input);

    // Then: 결과 검증
    assertThat(result).isEqualTo("expected");
}
```

### 4. AssertJ 체이닝
```java
assertThat(result)
    .isNotNull()
    .hasSize(2)
    .containsKey("제주항공");
```
