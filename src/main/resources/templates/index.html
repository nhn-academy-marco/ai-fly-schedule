Agent 패턴 비교 실습

이 실습의 질문 다음 단계를 누가 결정하는가 — 코드인가, LLM인가?

같은 문장을 세 가지 패턴으로 동시에 처리합니다. 실행 기록(trace)의 색을 보면 각 단계를 코드·LLM·Tool·Worker 중 누가 결정했는지 알 수 있습니다.

Coordinator

7장 읽기 →
코드가 순서 결정→ 전문 Agent 7단계

처리 순서가 코드에 고정되어 있습니다. LLM은 정규식으로 검색 조건을 뽑지 못할 때만 씁니다. 빠르고 결과가 항상 같습니다.

POST /api/search/coordinator

Tool Calling Agent

8장 읽기 →
LLM이 Tool 선택⇄ Tool 실행

LLM이 어떤 Tool을 어떤 인자로 몇 번 부를지 결정합니다. 유연하지만 모델에 따라 결과와 속도가 달라집니다.

POST /api/search/tool-calling

Orchestrator-Workers

9장 읽기 →
LLM이 작업 분해→ Worker 병렬 실행→ LLM이 종합

조건이 여러 개인 요청을 LLM이 작업으로 나누고, Worker가 동시에 검색한 뒤, LLM이 결과를 비교해 추천합니다.

POST /api/search/orchestrator
LLM
실행할 패턴
실행 기록 색 CODE · 개발자가 순서 결정 LLM · 판단·계획·요약 TOOL · LLM이 호출 요청 WORKER · Orchestrator가 맡긴 작업

예시를 고르거나 문장을 입력한 뒤 실행해 보세요. LLM을 쓰는 패턴은 모델에 따라 수십 초가 걸릴 수 있습니다.
