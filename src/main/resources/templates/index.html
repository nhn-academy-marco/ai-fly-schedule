MCP API 엔드포인트

항공편 검색

  • GET /api/mcp/flights/search?departure={출발공항}&arrival={도착공항}&date={날짜}
  • GET /api/mcp/flights/search/time?...&afterTime={시간}
  • GET /api/mcp/flights/search/price?...&minPrice={최소가격}&maxPrice={최대가격}

공항 정보

  • GET /api/mcp/airports - 전체 공항 목록
  • GET /api/mcp/airports/code?airportName={공항명} - 공항 코드 조회

항공사 정보

  • GET /api/mcp/airlines - 전체 항공사 목록
  • GET /api/mcp/airlines/id?airlineName={항공사명} - 항공사 ID 조회

사용 예시

cURL 예제

# 항공편 검색
curl "http://localhost:8080/api/mcp/flights/search?departure=광주&arrival=제주&date=내일"

# 오후 2시 이후 출발 항공편 검색
curl "http://localhost:8080/api/mcp/flights/search/time?departure=광주&arrival=제주&date=내일&afterTime=14:00"

# 가격 범위 필터링
curl "http://localhost:8080/api/mcp/flights/search/price?departure=광주&arrival=제주&date=내일&minPrice=30000&maxPrice=70000"

A2A 에이전트 흐름

사용자: "내일 광주에서 제주로 가는 항공편 알려줘"
Coordinator Agent: 사용자 의도 파악
Date Parser Agent: "내일" → "20260310" 변환
Airport Code Agent: "광주" → "NAARKJJ", "제주" → "NAARKPC"
Flight Search Agent: 공공데이터 API 호출
Grouping Agent: 항공사별 그룹핑
Response Formatter Agent: 자연어로 변환

자연어 처리

"내일", "모레", "오후 2시" 등 자연어 이해
